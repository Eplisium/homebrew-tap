# Eplisium Homebrew tap

```sh
brew install --cask eplisium/tap/omega-journal
```

| Cask | App |
| --- | --- |
| `omega-journal` | [Omega Journal](https://github.com/Eplisium/omega-journal): a private, encrypted journal for macOS 14+. Signed with a Developer ID and notarized by Apple. |

Update with `brew upgrade --cask omega-journal`.

`brew uninstall --zap omega-journal` also deletes the journal database and settings. Back up first (Settings → Data & Backups). The encryption key in your Keychain is left in place.
